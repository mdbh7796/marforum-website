{% trans "Google OAuth2 Setup" %}

Prerequisites

  1. A Google Cloud Console account
  2. A project created in Google Cloud Console

Steps to Configure

  1. Create OAuth 2.0 Credentials:
    • Go to Google Cloud Console Credentials
    • Click "Create Credentials" → "OAuth client ID"
    • Application type: "Web application"
    • Name: "Blog Directory" (or your choice)
  2. Configure Authorized Redirect URIs:
    • Add the following URI:
    • http://127.0.0.1:8000/accounts/google/login/callback/
    • For production, also add your domain:
    • https://yourdomain.com/accounts/google/login/callback/
  3. Get Your Credentials:
    • Copy the "Client ID" and "Client Secret"
    • Add them to your .env file:
    GOOGLE_OAUTH_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  4. Enable Google+ API:
    • Go to Google Cloud Console API Library
    • Search for "Google+ API"
    • Click "Enable"
Note: Make sure your SITE_ID in Django settings matches the site where users will log in.
